# Ardessa — деньги и дела

*Ardessa Corporation.* Раньше приложение называлось «Капитал».

Мобильное веб-приложение для управления деньгами и делами, рассчитанное в
первую очередь на iPhone 16 Pro. Устанавливается на экран «Домой» и работает
как обычное приложение, в том числе без интернета.

Все данные хранятся только на устройстве, в памяти браузера. Серверов и
подключений к банкам нет.

## Оформление

Строгий минимализм в японском духе: глубокий чёрный «суми» (в светлой
теме — тёплая бумага «васи»), один акцент — красный цвет логотипа Ardessa
— для главных действий и нефритовый цвет для поступлений. Карты кошельков — «литые» градиенты с
мелким зерном, тонким узором сиппо и бликом, который скользит по карте при
свайпе; карта отбрасывает на страницу мягкий свет своего цвета. При запуске
логотип собирается сам: парус прорисовывается одним штрихом, заливается
красным от корпуса к вершине и ловит блик, затем проявляются ARDESSA и
CORPORATION; главный экран собирается по шагам, баланс отсчитывается от
нуля. Нижняя навигация — плавающая стеклянная капсула.
Если в системе включено «Уменьшение движения» или в настройках выключены
анимации, вступление не показывается.

Крупные заголовки набраны Montserrat Bold — открытым шрифтом, ближайшим к
надписи ARDESSA; подписи разделов — спокойным строчным начертанием, без
капса. Красный — только для действий, бренда и предупреждений; графики и
полосы прогресса — нейтральные.

Суммы набраны отдельным шрифтом для цифр — его можно выбрать в
«Настройки → Оформление → Цифры»: изящные (Manrope, по умолчанию), строгие
(Geist), широкие (Unbounded) или системные. Шрифты лежат в
`src/assets/fonts` (только латинские подмножества, лицензия SIL OFL 1.1) и
работают без интернета.

## Дела: как пользоваться

Вкладка **«Дела»** — для всего, что не про деньги, но тоже нужно не забыть.
Метод простой, и приложение ведёт по нему само:

1. **Записывайте сразу.** Кнопка «+» (или «Записать дело» на главной) —
   и одна строка: «Позвонить маме завтра в 18:00», «отчёт к пятнице
   #работа !!». Дата, время, повтор («каждый понедельник», «по будням»),
   список (`#работа`) и важность (`!` или `!!`) распознаются сами и
   показываются чипами — лишнее снимается крестиком. Несколько строк —
   несколько дел. Без даты и списка дело попадает во «Входящие».
2. **Утром — план.** «Спланировать день»: разобрать хвосты с прошлых дней
   и входящие, выбрать до трёх главных дел. В конце — «Начните с…».
3. **Вечером — итоги.** «Подвести итоги»: что сделано, перенести
   остальное на завтра одной кнопкой, пара строк в дневник.

Что внутри:

- **Сегодня** — прогресс дня в виде энсо (круг тушью заполняется по мере
  дел, в конце ставится красная печать), главное дня с печатями-ханко,
  остальное по времени, хвосты, платежи на сегодня из финансов.
- **Неделя** — нагрузка по дням и дела каждого дня, рядом — платежи.
- **Списки** — «Входящие», «Сегодня», «Скоро», «Все дела», свои списки
  (сферы жизни или проекты со сроком и прогрессом), история сделанного и
  ритм по дням.
- **Заметки** — карточки, поиск, теги, закрепление, **дневник** на каждый
  день и **чек-листы**, пункты которых одной кнопкой превращаются в дела.
  Заметки связываются со списками, делами, целями, планами и долгами.
- **Дело** — пункты (подзадачи), дата и время, повтор (каждый день, по
  будням, неделя, месяц, год), список, приоритет, «главное на сегодня»,
  заметки к делу. Свайп влево — «Завтра» или «Удалить».
- **Напоминания.** Веб-приложение на iPhone не может само присылать
  уведомления, поэтому у дела с датой есть кнопка «Добавить в Календарь»:
  событие с напоминанием попадает в Календарь телефона и напомнит, даже
  если приложение закрыто.

## Что внутри (финансы)

- **Главная.** Карта с балансом (свайп между кошельками и «Все счета»),
  три действия «Доход / Расход / Перемещение», **«Можно потратить
  сегодня»**, последние операции, главная цель и одно подсказывающее
  наблюдение — только если оно актуально. После сохранения сумма
  «влетает» в карту.
- **Кошельки.** Чистый капитал с графиком за 90 дней, стопка карт,
  финансовая подушка, детальный экран кошелька с историей баланса,
  корректировкой, архивом и удалением.
- **Операции.** Поиск (по тексту, тегу или сумме), фильтры по периоду, типу,
  категории и кошельку, сортировка, группировка по дням, свайп для удаления.
- **Аналитика.** Неделя, месяц, квартал или год: сверху доходы, расходы и
  поток, ниже три коротких раздела. «Обзор» — график по дням с касанием,
  прогноз до конца месяца, наблюдения; «Категории» — кольцевая диаграмма со
  сравнением с прошлым периодом и календарь трат; «Тренды» — капитал и
  накопления, полгода, привычки. **Итоги месяца** — в формате
  историй: сколько ушло, куда, что сбережено, самая крупная трата, ритм.
- **Ещё.** Цели (свой баланс или привязка к кошельку, рекомендуемый взнос,
  прогноз), бюджеты с лимитами, планы с календарём и прогнозом свободных
  средств, подписки и регулярные платежи, долги, задачи, заметки со
  связями, категории, настройки, резервные копии.
- **Операция:** окно ввода построено как путь денег «Откуда → Куда»
  (кошелёк → категория, источник → кошелёк, кошелёк → кошелёк); цвет
  переключателя, подсветки и кнопки показывает тип. Сумму можно посчитать
  прямо в поле: 1 200 + 350, 450 × 3. Одна строка быстрых категорий и
  шаблонов, остальное — значками в одну линию: дата, комментарий (с
  подсказкой категории «как в прошлый раз»), теги, повтор, разделение
  чека, фото (хранятся только на устройстве).
- **Первый запуск:** короткое знакомство — имя, валюта, счета с остатками
  (или демо-данные).
- **Защита:** код-пароль из 4 цифр и вход по Face ID; блокировка сразу или
  через 1/5/15 минут в фоне.
- **Данные:** хранятся в IndexedDB (а не в маленьком localStorage), браузер
  просят не очищать их; копия в «Файлы» / iCloud одной кнопкой и
  напоминание раз в неделю; ежедневные автокопии; при сбое — экран
  восстановления с сохранением данных.
- **Курсы ЦБ РФ** подтягиваются сами раз в день (можно выключить и задавать
  вручную).
- **Оформление:** акцент (Ardessa, киноварь, индиго, сакура, золото), шрифт цифр,
  размер текста, тёмная и светлая тема; открытие сразу на вводе расхода.
- Глобальный поиск, отмена последнего действия, скрытие сумм, тактильный
  отклик, учёт `prefers-reduced-motion`.

### Правила учёта

- Суммы хранятся в копейках, без ошибок округления.
- Балансы не хранятся, а вычисляются из истории операций, поэтому после
  правки или удаления операции всё пересчитывается само.
- Переводы между своими кошельками, долги, цели и корректировки баланса
  не считаются доходами или расходами.
- Суммы в разных валютах складываются только по курсу — официальному
  курсу ЦБ или заданному вручную. Если курса нет, сумма честно исключается
  из общего баланса, и приложение показывает, какая валюта не учтена.
- Разделённый чек — это обычные расходы в разных категориях с общей
  меткой, поэтому бюджеты и аналитика считают каждую часть отдельно.
- «Можно потратить сегодня» = (деньги на повседневных счетах + ожидаемые
  поступления − платежи, планы и долги до конца месяца) / дни до конца
  месяца, а при общем бюджете — не больше, чем он позволяет. Трата
  сегодня уменьшает цифру ровно на свою сумму, переводы между своими
  счетами её не меняют.
- Данные первой версии приложения (`finance-data-v1`) переносятся
  автоматически при первом запуске.

### Правила дел

- Дело без даты и без списка — во «Входящих».
- Главных дел на день — не больше трёх; выбранное главным переносится на
  сегодня.
- Повторяющееся дело при отметке создаёт следующее (никогда не в прошлом);
  если отметку снять, следующее убирается.
- Удаление списка удаляет и его дела (отменить можно сразу же); чтобы
  сохранить дела, список убирают в архив.
- Старые резервные копии без списков открываются как есть.

## Запуск

Нужен Node.js 18 или новее.

```
npm install
npm run dev        # http://localhost:5173
npm test           # проверки учёта и дел: балансы, валюты, разбор строки, повторы
npm run build      # production-сборка в dist/
npm run e2e        # сценарии в браузере (Playwright, Chromium)
```

На GitHub каждый push проверяется автоматически (`.github/workflows/ci.yml`):
типы, проверки учёта, сборка и сценарии в браузере.

## Как установить на iPhone

1. Загрузите репозиторий на GitHub (структуру папок `src/`, `public/`
   нужно сохранить).
2. На vercel.com: **Add New → Project**, выберите репозиторий и нажмите
   **Deploy**. Vercel сам определит Vite-проект.
3. Откройте полученную ссылку в **Safari**, нажмите «Поделиться» →
   **«На экран Домой»**.

Обновления: после каждого push в GitHub Vercel пересобирает приложение,
а установленная копия обновится при следующем запуске или при возвращении
в приложение спустя 10 минут.

Чтобы перенести данные на другое устройство, используйте «Ещё → Настройки →
Резервные копии и данные → Сохранить копию в Файлы» и «Импорт из файла» на
новом устройстве.

## Архитектура

```
src/
  lib/        чистая логика: деньги, даты, балансы, аналитика, прогнозы,
              дела (tasks.ts), разбор строки (quickParse.ts), календарь (ics.ts)
  store/      Zustand-хранилище с сохранением в IndexedDB, запуск и первый
              вход, фото чеков, демо-данные, перенос со старой версии, отмена
  ui/         дизайн-система: кнопки, списки, шторки, карта, клавиатура суммы;
              логотип Ardessa (Brand.tsx, контуры — brandPaths.ts)
  charts/     собственные SVG-графики (столбцы, линия, кольцо)
  nav/        вкладки, стек экранов со свайпом назад
  features/   экраны и формы по разделам; planner/ — вкладка «Дела»
  styles/     дизайн-токены (цвета, тени) для тёмной и светлой темы
tests/        проверки учёта
e2e/          сценарии в браузере
```

Стек: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Zustand,
Lucide, vite-plugin-pwa.
