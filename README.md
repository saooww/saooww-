# Капитал — личные финансы

Мобильное веб-приложение для управления деньгами, рассчитанное в первую
очередь на iPhone 16 Pro. Устанавливается на экран «Домой» и работает как
обычное приложение, в том числе без интернета.

Все данные хранятся только на устройстве, в памяти браузера. Серверов и
подключений к банкам нет.

## Оформление

Строгий минимализм в японском духе: глубокий чёрный «суми» (в светлой
теме — тёплая бумага «васи»), один киноварный акцент для главных действий
и нефритовый цвет для поступлений. Карты кошельков — «литые» градиенты с
мелким зерном, тонким узором сиппо и бликом, который скользит по карте при
свайпе; карта отбрасывает на страницу мягкий свет своего цвета. При запуске
знак «К» прорисовывается сам, а главный экран собирается по шагам; баланс
отсчитывается от нуля. Нижняя навигация — плавающая стеклянная капсула.
Если в системе включено «Уменьшение движения» или в настройках выключены
анимации, вступление не показывается.

## Что внутри

- **Главная.** Карта с балансом (свайп между кошельками и «Все счета»),
  три действия «Доход / Расход / Перемещение», последние операции, главная
  цель и одно подсказывающее наблюдение — только если оно актуально.
- **Кошельки.** Чистый капитал с графиком за 90 дней, стопка карт,
  финансовая подушка, детальный экран кошелька с историей баланса,
  корректировкой, архивом и удалением.
- **Операции.** Поиск (по тексту, тегу или сумме), фильтры по периоду, типу,
  категории и кошельку, сортировка, группировка по дням, свайп для удаления.
- **Аналитика.** Неделя, месяц, квартал или год: доходы, расходы и денежный
  поток, график по дням с касанием, прогноз до конца месяца, категории
  (кольцевая диаграмма и сравнение с прошлым периодом), капитал и
  накопления, полгода, привычки и наблюдения.
- **Ещё.** Цели (свой баланс или привязка к кошельку, рекомендуемый взнос,
  прогноз), бюджеты с лимитами, планы с календарём и прогнозом свободных
  средств, подписки и регулярные платежи, долги, задачи, заметки со
  связями, категории, настройки, резервные копии.
- Глобальный поиск, избранные операции, отмена последнего действия,
  тёмная и светлая тема, скрытие сумм, тактильный отклик, учёт
  `prefers-reduced-motion`.

### Правила учёта

- Суммы хранятся в копейках, без ошибок округления.
- Балансы не хранятся, а вычисляются из истории операций, поэтому после
  правки или удаления операции всё пересчитывается само.
- Переводы между своими кошельками, долги, цели и корректировки баланса
  не считаются доходами или расходами.
- Суммы в разных валютах складываются только по курсу, заданному
  пользователем. Если курса нет, сумма честно исключается из общего
  баланса, и приложение показывает, какая валюта не учтена.
- Данные первой версии приложения (`finance-data-v1`) переносятся
  автоматически при первом запуске.

## Запуск

Нужен Node.js 18 или новее.

```
npm install
npm run dev        # http://localhost:5173
npm test           # проверки учёта: балансы, переводы, долги, цели, валюты
npm run build      # production-сборка в dist/
```

## Как установить на iPhone

1. Загрузите репозиторий на GitHub (структуру папок `src/`, `public/`
   нужно сохранить).
2. На vercel.com: **Add New → Project**, выберите репозиторий и нажмите
   **Deploy**. Vercel сам определит Vite-проект.
3. Откройте полученную ссылку в **Safari**, нажмите «Поделиться» →
   **«На экран Домой»**.

Обновления: после каждого push в GitHub Vercel пересобирает приложение,
а установленная копия обновится при следующем запуске.

Чтобы перенести данные на другое устройство, используйте «Ещё → Настройки →
Резервные копии и данные → Экспорт / Импорт».

## Архитектура

```
src/
  lib/        чистая логика: деньги, даты, балансы, аналитика, прогнозы
  store/      Zustand-хранилище с сохранением в localStorage, демо-данные,
              перенос со старой версии, отмена действий
  ui/         дизайн-система: кнопки, списки, шторки, карта, клавиатура суммы
  charts/     собственные SVG-графики (столбцы, линия, кольцо)
  nav/        вкладки, стек экранов со свайпом назад
  features/   экраны и формы по разделам
  styles/     дизайн-токены (цвета, тени) для тёмной и светлой темы
tests/        проверки учёта
```

Стек: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Zustand,
Lucide, vite-plugin-pwa.
