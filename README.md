# Капитал — как превратить в полноценное приложение на iPhone

Это обычный веб-проект (React + Vite). Ничего программировать не нужно — Vercel
сам соберёт и запустит приложение. Шаги ниже займут 5–10 минут.

## Шаг 1. Загрузите проект на GitHub (без командной строки)

1. Зайдите на github.com и создайте бесплатный аккаунт (если его ещё нет).
2. Нажмите **New repository**, назовите его, например, `kapital-app`, оставьте
   приватным или публичным — на ваш выбор. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите в окно браузера **все файлы и папки из этого архива** (сохраняя
   структуру: `src/`, `public/`, `index.html`, `package.json` и т.д.).
5. Нажмите **Commit changes**.

## Шаг 2. Разверните на Vercel (бесплатно)

1. Зайдите на vercel.com → **Sign up** → войдите через GitHub.
2. Нажмите **Add New → Project**.
3. Выберите репозиторий `kapital-app`, который вы только что создали.
4. Vercel сам определит, что это Vite-проект — просто нажмите **Deploy**.
5. Через минуту вы получите настоящую ссылку вида `kapital-app.vercel.app`.

## Шаг 3. Установите на iPhone как приложение

1. Откройте полученную ссылку в **Safari** на iPhone (обязательно в Safari,
   не в Chrome и не в приложении Claude).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран Домой»**.
4. Готово — на рабочем столе появится иконка «Капитал». Она откроется на весь
   экран, без адресной строки, со сплэш-экраном при запуске и будет работать
   даже без интернета (данные уже загруженные ранее останутся доступны).

## Что уже настроено внутри проекта

- `vite-plugin-pwa` — автоматически создаёт service worker для офлайн-режима
  и файл манифеста (`manifest.webmanifest`), который делает приложение
  «настоящим»: свой значок, отдельное окно, сплэш-экран.
- Иконки уже лежат в `public/icons/` — при желании замените их своими
  (PNG, 192×192, 512×512 и 180×180 для iOS).
- Все данные (кошельки, операции, долги, цели) сохраняются в памяти самого
  телефона через `localStorage` — они останутся на месте после перезапуска
  и офлайн, но принадлежат конкретному браузеру/устройству, поэтому между
  iPhone и компьютером данные не синхронизируются автоматически.

## Обновление приложения в будущем

Если попросите Claude что-то доработать в этом проекте — просто загрузите
изменённые файлы поверх старых в тот же репозиторий на GitHub (тот же шаг
«uploading an existing file», подтвердите замену). Vercel автоматически
пересоберёт и обновит приложение по той же ссылке за минуту.

## Локальная проверка (по желанию, если есть Node.js на компьютере)

```
npm install
npm run dev
```

Откроется на `http://localhost:5173`.
